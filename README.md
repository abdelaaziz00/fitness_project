
# AZfit — Fitness & Nutrition Web Application

AZfit is a web application project focused on fitness and nutrition. It explores how a web platform can support users in managing fitness-related activities and nutrition information.

## Project Overview

This repository contains the AZfit application source code and a SQL database export (`azfit.sql`). It demonstrates the integration of a web interface, server-side PHP code, and relational data storage.

## Technology Stack

- **PHP** — Server-side application logic
- **JavaScript** — Client-side interactions
- **HTML & CSS** — Page structure and styling
- **SQL** — Relational database structure and data

## Repository Structure

```text
fitness_project/
├── AZfit/       # Application source files
├── azfit.sql    # SQL database export
└── README.md    # Project documentation
```

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/abdelaaziz00/fitness_project.git
cd fitness_project
```

2. Set up a local web server with PHP support, such as **XAMPP**.
3. Import `azfit.sql` into a compatible local database server.
4. Configure the database connection settings in the application source under `AZfit/`.
5. Serve the application through your PHP-enabled web server.

> **Note:** The precise application entry point, PHP version, database requirements, and configuration steps still need verification against the source code.
